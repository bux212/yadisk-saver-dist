# YaDisk Saver — готовые сборки

Здесь лежат **собранные архивы** расширения для Chrome / Edge.
Репозиторий публичный, чтобы любой мог скачать обновление по ссылке.
Исходники отдельно: [bux212/yadisk-saver](https://github.com/bux212/yadisk-saver).

## Скачать

Постоянная ссылка на последнюю версию:
`https://github.com/bux212/yadisk-saver-dist/releases/latest/download/yadisk-saver-latest.zip`

## Как обновить расширение

Chrome не умеет обновлять распакованное расширение сам, поэтому:

1. скачать zip;
2. распаковать его **поверх** старой папки расширения (файлы заменятся);
3. открыть `chrome://extensions` и нажать ⟳ у расширения YaDisk Saver.

Рядом с каждым архивом лежит `.sha256` — сверка целостности.
